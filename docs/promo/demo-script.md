# TreeWorld Demo 录屏脚本（30-45 秒）

## 准备工作

- 工具：KDE 自带 **Spectacle**（录视频）或 `kooha`（更轻，pacman -S kooha）
  - Spectacle：打开 → 录像模式 → 选窗口区域 → 开始
- 先把画布清空（新建一个画布），配好 API key（Claude/OpenAI/Ollama 都行，本地 Ollama 反而加分——"本地优先"是卖点）
- 分辨率 1920x1080 或 2560x1440，关掉通知
- 录完用 `ffmpeg -i in.mp4 -vf "fps=12,scale=1280:-1" out.gif` 转 GIF（或直接发视频）

## 分镜（6 段，总时长 30-45 秒）

### 段 1：开场 — 画布即桌面（3 秒）
- 动作：画布上已有几个便签/图片块，做一次平移 + 缩放（Ctrl+滚轮）
- 字幕：TreeWorld — 你和 AI 共用的一块无限画布

### 段 2：唤起对话（3 秒）
- 动作：按 `/`，输入框弹出
- 字幕：按 / 随时唤起 AI

### 段 3：说需求（5 秒）
- 动作：输入「帮我整理一份 Arch Linux 上用 Tauri 打包的注意事项」，回车
- 状态条显示 "Agent 正在搜索..."（触发 Tavily 联网搜索，展示搜索能力）
- 字幕：它会先搜索最新资料

### 段 4：计划确认（5 秒）
- 动作：AI 返回计划卡片（集合框 + 3-5 个块，每个块带类型和理由）
- 字幕：先给计划，你确认才动手

### 段 5：一键生成（8 秒）
- 动作：点「确认执行」→ 画布上出现集合框，块逐个排入（避让已有内容）
- 字幕：确认后自动生成结构化成果

### 段 6：让它改 + 锁定保护（10-15 秒）
- 动作 A：输入「把第二点展开详细写」→ AI 用 canvas.query 查那块完整内容 → 更新
- 动作 B（可选加分）：锁定一个块，输入「删掉这个块」→ AI 出黄色警告便签「已被锁定，需先解锁」
- 字幕：能查能改；你锁定的块，AI 动不了

## 发布配套

- GIF/视频首帧要好看（第一帧停在布局最满的画布上）
- 配一条发帖文案（见文章初稿结尾的推广段）
- 文件名：treeworld-demo.gif，放 README 顶部 + 帖子首图

## 雷区

- 别录 API key 配置界面
- 别录加载/思考转圈太久（可以剪掉等待段，GIF 循环最忌停顿）
- Agent 生成失败就重录，别把报错剪进去当彩蛋（HN 上会翻车）
